## How to Run Task 6

1. Create the database using `sql/database.sql`.
2. Configure the MySQL username and password using environment variables.
3. Open the Task06_EventRegistration folder in the terminal.
4. Run:

   `mvn clean compile`

5. Start the application:

   `mvn exec:java "-Dexec.mainClass=ui.EventRegistrationApp"`
